# CompeteHub

Discover hackathons and Capture The Flag (CTF) competitions in one place.

Our goal is to help students discover opportunities, track deadlines, and register through official event websites.

## Current Features

- Search competitions
- Filter by Hackathons and CTFs
- Responsive competition discovery page

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Project Status

Currently under development. Event cards contain sample data; real competition aggregation is planned next.
